# Sewing Machine 3D Showcase

Site interativo para visualizacao de uma maquina de costura em 3D, desenvolvido com Vite e `@google/model-viewer`.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build de producao

```bash
npm ci
npm run build
npm run preview
```

O deploy no GitHub Pages e executado automaticamente pelo GitHub Actions a cada envio para a branch `main`.
